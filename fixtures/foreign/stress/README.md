# Stress fixtures (audit 02)

These are the decks from audit 02's adversarial corpus that the acceptance criteria
AC-13 to AC-20 use. The decks are byte-identical copies of `stress-corpus/decks/`,
whose `docProps` authors the auditor rewrote to `Tyler`. The builders in `src/` are
copies of `stress-corpus/src/`. They were changed only in their output paths, the
test photo, and the identity (`_stress.py`). Each changed file says so in its first
line.

| deck | builder | used by |
|---|---|---|
| `d15_ppx_style_fontref.pptx` | `ppx_style_text.py` | AC-15 |
| `d16_raw_color.pptx` | `raw_color.py` | AC-19 |
| `d17_raw_geometry.pptx` | `raw_geometry.py` | AC-16 |
| `d18_lo_autofit.pptx` | `lo_autofit.py` + `lo_autofit.sh` (LibreOffice) | AC-18 |
| `d20_pgx_slop.pptx` | `pgx_slop.js` (pptxgenjs 4.0.1) | AC-17 |
| `d25_ppx_localized_names.pptx` | `ppx_localized_names.py` | AC-13 |
| `d27_strict_from_ppx.pptx` | `ppx_layouts.py` → `strict_convert.py` | AC-14 |
| `o51`…`o56` | `raw_oddities.py` | AC-14 |
| `perf_1000`, `perf_150_x60` (generated by the test, not committed) | `perf_shapes.py` | AC-20 |

## Rebuild

```sh
cd fixtures/foreign/stress/src
python ppx_style_text.py          # and raw_color.py, raw_geometry.py, ppx_localized_names.py
python ppx_layouts.py /tmp/d02.pptx && python strict_convert.py /tmp/d02.pptx
python raw_oddities.py
PYTHON=python bash lo_autofit.sh                         # needs soffice
node pgx_slop.js && python _stress.py retag ../d20_pgx_slop.pptx   # needs pptxgenjs
python perf_shapes.py /tmp/perf perf_1000 perf_150_x60
```

`tests/rules/test_fixture_repro.py` rebuilds the 12 decks made with python-pptx and
compares every part with the committed deck (`docProps` excluded).

**Version-dependent:** `d18` holds whatever `normAutofit@fontScale` LibreOffice computes.
The committed deck comes from LibreOffice 24.2.7.2 (`fontScale="28122"`). LibreOffice
26.8.0.3 writes `fontScale="40000"` for the same input. AC-18's "about 9.0 pt" refers
to the committed deck. pptxgenjs 4.0.1 reproduces `d20` part for part.
